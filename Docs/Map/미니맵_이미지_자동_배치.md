# 미니맵 이미지 자동 배치

M 키로 지도를 열면 `MapView`가 `Resources/UI/MapRooms`의 Sprite를 읽고 방 JSON의 점유 청크에 맞춰 UI Image를 생성한다. 현재는 리전 1의 A01~A06, 리전 2의 B01~B12, 리전 3의 C01~C12 총 30개 방 이미지가 들어 있다.

## 이름과 파일 위치

예: `Assets/Resources/UI/MapRooms/Room_A04_minimap.png`

`_minimap` 접미사를 제거한 `Room_A04`가 `MapRoomData.json`의 `Id`와 일치해야 한다. 접미사 없이 `Room_A04.png`로 두어도 된다. 대소문자는 구분한다. 이미지 이름에 좌표나 출입구 정보를 넣지 않으며, 실제 배치는 JSON이 결정한다.

새 방의 JSON을 등록하고 같은 이름의 Sprite 이미지를 추가하면 별도의 방 모양 프리팹 연결 없이 표시된다. 이미지를 추가하거나 교체한 뒤 Unity 임포트를 마치고 플레이를 다시 시작한다. 이미지가 없는 방은 생성하지 않는다. 같은 ID를 가진 이미지가 둘이면 경고한다.

## 크기와 좌표

- 기준은 청크당 250×250 UI 단위다. 화면 안에 들어가도록 방 전체를 같은 비율로 축소한다.
- `MapView`의 Display Scale 기본값은 `0.25`다. 화면 맞춤 배율을 계산한 다음 가로·세로를 각각 기존의 25%로 줄인다. 크기와 좌표에 같은 배율을 적용한다. 위치는 프리팹의 MapOrigin이 결정한다.
- 위치는 점유 청크의 최소 X·Y에 청크 크기를 곱한다.
- 크기는 점유 청크의 가로·세로 전체 범위로 계산한다. 예를 들어 A02는 500×500, A03은 500×250이다.
- L자 방도 전체 사각형 캔버스를 유지하고 빈 청크는 투명하게 둔다.
- 이미지와 데이터 영역의 가로세로 비율이 맞지 않으면 오류를 표시하고 해당 방은 건너뛴다.
- 원점은 모든 방에 공통으로 적용되므로 A03 상단과 A04 하단 등 다른 방향의 통로도 일치한다.

## 이미지 Import 설정

현재 포함된 PNG의 설정은 다음과 같다.

- Texture Type: Sprite (2D and UI)
- Sprite Mode: Single
- Mesh Type: Full Rect
- Pixels Per Unit: 250
- Generate Mip Maps: 끔
- Compression: None
- Wrap Mode: Clamp

투명 영역을 잘라내거나 Tight Mesh로 바꾸지 않는다. 이미지는 기존 시안 PNG와 동일한 원본이다.

## 현재 표시 동작

### 지도 시작 위치를 프리팹에서 조절

`Assets/Resources/UI/PopupUI/Map.prefab`을 열어 `Map > MapOrigin`을 선택하고 RectTransform의 Pos X / Pos Y 또는 Scene 뷰 이동 핸들을 조절한다. X 양수는 오른쪽, Y 양수는 위쪽이다. MapOrigin은 JSON 청크 `(0,0)` 사각형의 왼쪽 아래 기준점이다. 방 중앙이나 플레이어의 월드 스폰 위치와는 별개다.

구조는 `Map > MapOrigin > MapContent > 실행 중 생성되는 방 이미지`다. MapView의 Transform_MapOrigin에는 해당 오브젝트를 연결해 두었다. 스크립트는 MapOrigin의 위치를 변경하지 않는다. MapContent는 기준점에 맞춰 위치 0을 유지하고 크기만 조절하므로 위치 수정은 MapContent 대신 MapOrigin에서 한다. 프리팹 편집 후 저장하면 다음 지도 생성부터 반영된다.

현재 리전에 속한 방만 활성화하고, 그중 방문 기록(`IsVisited`)이 있는 방의 이미지만 표시한다. 처음 방에 들어가 방문 상태가 바뀌면 즉시 나타나고, 떠난 방도 방문 기록이 유지되므로 계속 보인다. 텔레포트 등으로 지형 정보만 공개되어도 직접 방문하지 않은 방은 숨긴다.

숨길 때 Image 렌더링만 끄므로 방문 상태 변경 구독은 유지한다. 지도 창을 닫은 동안 방문한 방도 다시 열면 최신 상태로 표시한다. 전체 지역의 크기와 배치를 기준으로 화면을 맞추므로 방이 공개될 때마다 지도 위치나 배율이 바뀌지 않는다.

리전이 바뀌면 기존 객체를 다시 사용하며 해당 리전의 이미지가 없으면 비어 있는 지도가 된다. M 키로 닫았다 열어도 같은 ViewModel의 방을 중복 생성하지 않는다. 방 이미지 색감은 유지하고 현재 방에만 약한 녹색 강조를 적용한다.

히든 발견 표시, 지도 드래그·사용자 확대, 방 이름 텍스트와 상세 패널은 별도 기능이다. 방문 기록의 영구 저장·복원은 아직 연결되지 않았으므로 게임을 새로 실행하면 새 지도 상태로 시작한다.

## 주요 구현

테스트 중 Q 키를 누르면 모든 리전의 방을 방문/지형 공개 상태로 설정한다. M 키로 지도를 열어 확인할 수 있고, 이미 열려 있으면 즉시 반영된다. 화면에는 현재 리전만 표시하며 현재 방/리전, 보상 획득과 히든 발견 상태는 바꾸지 않는다. 해금 상태는 현재 실행 중에만 유지된다. 입력은 기존 MapUIInput에서 처리하며 별도 Inspector 연결은 필요 없다.

- `Assets/Scripts/UI/MapView.cs`: 이름→ID 매칭, Sprite 로드, 청크 배치, 리전 전환 및 화면 맞춤.
- `Assets/Scripts/UI/MapRoomView.cs`: 원본 이미지 색감 유지와 현재 방 강조.
- `Assets/Resources/UI/PopupUI/Map.prefab`: 자동 로드 폴더와 250단위 청크 설정.
